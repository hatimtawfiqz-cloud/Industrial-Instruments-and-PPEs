# Industrial-Instruments-and-PPEs
Tests learners' knowledge about types of technical tools and PPEs.
This vocabulary game aims at enhancing learners knowledge about technical tools and PPEs. The learner is required to identify an image by choosing a correct word from four options, once he chooses a word a screen pops up to give feedback with pronunciation, phonetic transcription, and a definition about the use of the item. The project is dedicated to technical learners of constructions, mechanics, electrician, and pipefittings.
